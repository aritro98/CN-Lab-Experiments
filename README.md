# Computer Networks Lab Experiments  

A comprehensive collection of all C-language lab experiments performed in our 3rd-year **Computer Networks** course. Each `Lab_X` directory contains one or more `progX.Y.c` programs that demonstrate and reinforce key networking concepts through hands-on implementation.  

## Topics Covered  
- **Socket Programming Fundamentals**: creating, binding, listening, accepting sockets  
- **Connectionless vs. Connection-oriented Models**: UDP sender/receiver and TCP client/server pairs  
- **Flow Control & Error Handling**: simple stop-and-wait and sliding-window protocols  
- **Multiplexing & I/O Models**: select/poll and concurrent server designs  
- **File Transfer & Remote Execution**: basic FTP-style file send/receive  
- **Custom Protocol Simulation**: framing, checksums, and ARQ mechanisms  
- **Performance Measurement**: measuring throughput and latency in C programs

## Repository Structure  
- Each experiment resides in its own folder named `Lab_X`.  
- Folders include **source code** and **sample outputs** or results.
